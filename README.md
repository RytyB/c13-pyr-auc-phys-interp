<h1> c13-pyr-auc-phys-interp </h1>
<p> For the interested reader of <i> Physiological Interpretation of the Lactate to Pyruvate AUC Ratio for Hyperpolarized [1-13C]-Pyruvate Studies </i> </p>
<br>
Ryan T Boyce, Collin J Harlan, Qing Wang, Christopher M Walker, Stephen Y Lai, Matthew E Merritt, James A Bankson
<br>

<h3> What's all this about? </h3>
This repository contains the simulations and data analysis code used to investigate the relationship between fitted pharmacokinetic parameters 
and the lactate to pyruvate AUC ratio for HP pyruvate experiments. Detailed descriptions of the experiments 
can be found in the full paper and the user's outputs can be easily checked against the figures. 

<h3> How do I get set up? </h3>
The repository is written entirely in MATLAB and requires the following toolboxes:
<br>
<li> Statistics and Machine Learning Toolbox </li>
<li> Parallel Computing Toolbox </li>
<br>
The repo can be downloaded from GitHub and unzipped. Simulations are stored in the directory called <i> Figure_Scripts </i> and raw data, including imaging data for the patient 
analyzed in the paper is included in <i> Data </i>. Necessary dependencies for calculations are included in the directory <i> Simulation_Functions </i>, but if the directory structure 
of the repo is not changed then these functions should already be added to the path when needed by simulations without user input.
